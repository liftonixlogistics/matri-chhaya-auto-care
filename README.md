# मातृ छाया — Matri Chhaya Auto Care

Ultra-fast mobile-first automotive landing page. No framework runtime or animation dependencies: static HTML, responsive CSS, and lightweight JavaScript.

## Features
- Premium cinematic automotive hero and full-screen touch navigation
- Swipeable visual service stories and filterable list of all nine shop services
- Working finger-swipe car cleaning canvas (illustrative demo)
- CSS wheel lab: tap to spin and select wheel-related services
- Touch-driven before/after **illustrative color-grade** comparison
- Select vehicle/services and copy or share a WhatsApp enquiry
- Mobile bottom action dock, responsive typography, reduced-motion support, lazy imagery

## Deployment
Vercel is connected to the GitHub `main` branch. A Git push automatically triggers a production deployment.
